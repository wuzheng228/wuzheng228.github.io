Markdown 是一种轻量级的标记语言，旨在让写作更简单、更结构化。它使用纯文本格式的语法来添加样式，如标题、列表、链接和代码块，使内容在转换为 HTML 或其他格式时保持美观。在 Hexo 博客中，Markdown 是默认的写作格式，因为它易于编写、阅读和编辑。

### 关键特点
- **简洁性**：语法简单，学习曲线低，专注于内容而非格式。
- **跨平台**：纯文本文件兼容性高，可以在各种设备和软件中编辑。
- **结构化**：支持标题、列表、引用、代码高亮等，便于组织长篇文章。
- **与 Hexo 集成**：Hexo 博客使用 Markdown 作为主要源文件，自动生成静态页面，提升写作效率。

### 基本示例
在 Markdown 中，您可以使用简单的符号来格式化文本：
- **标题**：用 `#` 表示（例如，`# 一级标题`）
- **粗体**：用 `**文本**` 包围（例如，`**加粗**`）
- **链接**：用 `[链接文本](URL)` 格式（例如，`[Hexo](https://hexo.io)`）
- **代码块**：用三个反引号包围（例如，` ```代码``` `）

### 在 Hexo 中的应用
撰写 Hexo 博客时，建议：
1. **熟悉基础语法**：掌握常见标记来快速编写文章。
2. **使用工具**：如 Typora 或 VS Code 的插件来实时预览。
3. **优化内容**：利用 Markdown 的清晰结构来润色和优化博客，增强可读性。
