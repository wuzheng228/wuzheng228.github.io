**安全警告 — 请仔细阅读。**

OpenClaw 是一个业余项目，目前仍处于测试阶段。请做好可能遇到问题的准备。  
默认情况下，OpenClaw 是一个个人助手：其信任边界仅限于一位受信任的操作者。  
如果启用了工具，此机器人可以读取文件并执行操作。  
不当的指令可能会诱使它执行不安全的行为。

默认情况下，OpenClaw **不** 是一个具备防御性的多租户边界。  
如果多个用户可以向一个启用了工具的助手发送消息，那么他们将共享该被委托的工具权限。

如果您对安全加固和访问控制不熟悉，请不要运行 OpenClaw。  
在启用工具或将其暴露到互联网之前，请先寻求有经验人士的帮助。

**推荐的基线措施：**
*   配对/白名单 + 提及门控。
*   多用户/共享收件箱：分割信任边界（使用独立的网关/凭据，最好使用独立的操作系统用户/主机）。
*   沙箱 + 最小权限工具。
*   共享收件箱：隔离私信会话 (`session.dmScope: per-channel-peer`)，并保持工具访问权限最小化。
*   将机密信息置于助手可访问的文件系统之外。
*   对于任何配备工具或拥有不受信任收件箱的机器人，请使用能力最强的可用模型。

**定期运行：**
```
openclaw security audit --deep
openclaw security audit --fix
```

**必须阅读：** https://docs.openclaw.ai/gateway/security
