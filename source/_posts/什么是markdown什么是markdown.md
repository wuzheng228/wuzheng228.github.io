# Markdown是什么

Markdown 是一种**轻量级标记语言**，它允许人们使用易读易写的纯文本格式编写文档，然后可以转换成结构化的 HTML 页面。

它的核心特点是：

1. **语法简单直观**：用几个简单的符号（如 `#`、`*`、`-`、`` ` ``) 就能对应 HTML 中的标题、列表、代码块等元素。
2. **专注于内容本身**：写作时无需频繁切换鼠标或记忆复杂的格式按钮，就像在记事本里写字一样流畅。
3. **通用性强**：被 GitHub、各类博客平台（包括 Hexo）、笔记软件等广泛支持，是程序员和内容创作者的常用工具。

**简单例子对比：**

* **Markdown 原文：**
  ```markdown
  # 这是一个一级标题
  这是一段**加粗**的文字和一个[链接](https://example.com)。
  - 列表项一
  - 列表项二
  ```
* **转换后的视觉效果：**
  > # 这是一个一级标题
  > 
  > 这是一段**加粗**的文字和一个[链接](https://example.com)。
  > 
  > - 列表项一
  > - 列表项二
